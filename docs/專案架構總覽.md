# 旭田移轉單系統 — 專案架構總覽

> 這份是「快速跟上」用的全貌整理。細節規格見 `01_系統架構與技術建議.md`、
> 開發規範見 `CLAUDE.md`、部署見 `docs/部署與維運.md`。

---

## 1. 一句話定位

家庭事業(金屬加工)的**移轉單數位化系統**:取代手寫三聯複寫單。
一個後端 API 服務多種裝置(筆電/平板/手機),**純移轉單**(無金額)、長輩友善、資安優先。

---

## 2. 技術堆疊

| 層 | 技術 |
|---|---|
| 前端 | React + Vite + TypeScript + Tailwind CSS;圖表 Recharts;節點畫布 React Flow |
| 後端 | Flask + Gunicorn;SQLAlchemy + Alembic(migration);pydantic(驗證) |
| 認證 | Flask-Login(session cookie)+ bcrypt + CSRF;Flask-Limiter(rate limit) |
| 資料庫 | PostgreSQL 16 |
| 快取/限流儲存 | Redis(Flask-Limiter 後端;多 worker 共用) |
| PDF | WeasyPrint(一般)+ ReportLab(點陣套表) |
| 列印 | CUPS(伺服器端) |
| 反向代理/TLS | Caddy(自動 Let's Encrypt) |
| 容器 | Docker + docker-compose |

---

## 3. 服務架構(容器)

```
裝置 ──HTTPS──> Caddy(唯一對外 80/443)
                 ├─ /api/* → backend(Flask+gunicorn)
                 └─ 其餘   → frontend(nginx 靜態檔)
                            backend ── db(PostgreSQL,內網)
                            backend ── redis(限流儲存,內網)
                            backend ── CUPS(列印)
```
只有 Caddy 對外;`frontend / backend / db / redis` 都只在 Docker 內網。

## 5. 資料模型(7 張表)

- **users**:帳號、bcrypt 密碼、角色(admin/operator)、is_active。
- **companies**:公司(role_type=vendor/receiver/both)。
- **products / specs / process_items**:品名 / 規格 / 加工項目(主檔)。
- **orders**:單頭(order_no、vendor/receiver、order_date、status、created_by…)。
- **order_items**:單身(逐行)。**反正規化快照**:`product_name/spec` 建單當下寫死,
  日後改主檔不影響歷史單據(單據系統的核心正確性)。
- **audit_log**:誰、何時、對什麼做了什麼(資安追溯)。

> 註:`unit_price/amount/total_amount` 欄位保留但目前**閒置**(純移轉單無金額;之後要做請款再啟用)。

## 6. API 一覽(統一回傳 `{ data, error }`)

| 群組 | 端點 |
|---|---|
| 認證 | `POST /auth/login`、`/logout`、`GET /auth/me`、`/auth/csrf` |
| 主檔 | `GET/POST /companies /products /process-items /specs`(寫入限 admin) |
| 訂單 | `GET /orders`(篩選+分頁)、`POST/GET/PUT/DELETE /orders/{id}` |
| 文件 | `GET/POST /orders/{id}/pdf`、`GET /orders/{id}/dotmatrix-pdf`、`POST /orders/{id}/print` |
| 報表 | `GET /reports/summary /by-product /by-company`(數量統計,DB 端聚合) |
| 列印 | `GET /print/calibration`、`GET/PUT /print/dotmatrix-layout` |
| 使用者 | `GET/POST/PATCH /users`(僅 admin;不回傳密碼) |

---

## 7. 主要功能

- **建單**:選擇頁 →(表單式 / 視覺化拖曳式)。兩者送同一支 `POST /orders`。
- **視覺化建單**:React Flow 畫布,廠商/接收/欄位各自節點,union-find 還原成「單頭+多排」;
  側欄分類拖曳(主檔值/自訂/最近使用組合)、移動/選取模式、右鍵選單、可折彎線、送出前確認。
- **訂單管理**:清單篩選/分頁、編輯、刪除(admin)、PDF 預覽、列印。
- **報表**:Bento + Recharts(總筆數/數量、每期數量、品名/廠商占比),聚合在 DB 端。
- **主檔**:所有人可看;新增限 admin。
- **使用者管理(admin)**:列出帳號、新增、改角色、停用/啟用、重設密碼(密碼不可檢視)。
- **列印**:一般機(WeasyPrint→CUPS)+ 點陣套表(ReportLab 座標 + 校正頁)。
