# 旭田興移轉單系統 — 系統介紹與操作

> 這份文件介紹:**聊天機器人可存取的資料**、**網頁架構**、以及**前端怎麼操作**。
> 刻意**只談前端操作與可查詢的業務資料**;後端技術細節、資安與隱私問題不在此說明
> (聊天機器人也會婉拒這類問題)。系統安全機制請另見 `docs/chatbot.md`、資料表完整定義見 `docs/資料庫結構.md`。

---

## 一、聊天機器人可存取的資料(可查詢範圍)

助理只能**查詢(唯讀)**以下業務資料,不能修改,也看不到帳號密碼、稽核紀錄等系統資料:

| 資料 | 內容 |
|---|---|
| **訂單 orders** | 單頭:單號、日期、廠商單位、接收單位、狀態 |
| **訂單明細 order_items** | 每筆品項:品名、規格、加工項目、重量、數量、單位、備註 |
| **廠商單位 / 接收單位 companies** | 名稱、縮寫、電話、傳真、地址;接收單位另有「加工方式」分類(如 CNC、研磨、車工、鑽孔…) |
| **品名 products** | 品名與備註 |
| **加工項目 process_items** | 加工項目名稱(可能是組合,如「車方孔、珠溝、單溝」) |
| **規格 specs** | 規格1 / 規格2 的值 |

可以問的例子:
- 「丞德有幾筆訂單?數量多少?」
- 「加工方式 CNC 有哪些接收單位?」
- 「哪些加工項目用到車方孔?」
- 「上個月各廠商的數量占比?」

> 小提醒:打錯字、同音字、用簡稱也沒關係(例:把「丞德」打成「承德」),助理會對照實際名稱盡量猜出你的意思。

## 二、網頁架構(頁面與導覽)

電腦版為**左側選單**,手機/平板為**底部導覽**。各頁面:

| 頁面 | 用途 | 權限 |
|---|---|---|
| 建單 | 建立移轉單(表單建立 / 拖曳建單) | 全部 |
| 出貨單 | 訂單清單:搜尋、篩選、開 PDF、編輯、刪除 | 全部 |
| 銷貨統計 | 依客戶與期間產生銷貨統計表 PDF | 全部 |
| 報表 | 數量趨勢、占比圖表 | 全部 |
| 主檔 | 維護廠商/接收/品名/加工項目/規格 | 全部 |
| 垃圾桶 | 還原 / 永久刪除已刪資料 | 管理員 |
| 使用紀錄 | 查看每位使用者的操作 | 管理員 |
| 設定 | 帳號管理、聊天機器人權限 | 管理員 |
| 右下角助理 | 自然語言查詢資料 | 依設定(關閉/僅管理員/所有人) |

## 三、前端怎麼操作

### 建單(總覽)
點「建單」後選一種方式:
- **表單建立**:傳統表格輸入,適合用鍵盤快速大量打單。
- **拖曳建單**:在畫布上把「欄位積木」拉出來、連成一排排品項,適合用滑鼠視覺化操作。

兩種方式都是建立同一種「移轉單」,單頭一樣(廠商、接收、日期),差別只在輸入品項的方式。
一張最多 **20 筆品項**;送出成功後可直接「開啟 PDF」。品項多到一張紙放不下時,PDF 會**自動分頁**,每張都有完整表頭與簽名欄,單號自動加 `-01`、`-02`…

#### 訂單欄位逐欄說明
單頭(整張單共用):
| 欄位 | 說明 | 必填 |
|---|---|---|
| 廠商單位 | 出貨/委外的廠商。輸入關鍵字可搜尋 | 是 |
| 接收單位 | 收料單位。**先選「加工方式」**(如 CNC、研磨),再從該方式的公司中挑 | 是 |
| 日期 | 移轉單日期 | 是 |
| 備註(整張單) | 整張單的備註,印在 PDF 下方 | 否 |

每一筆品項(可多筆):
| 欄位 | 說明 | 必填 |
|---|---|---|
| 加工單號 | 該筆品項的加工單號,可填可不填(留白就空白),印在 PDF 第一欄 | 否 |
| 品名 | 例:HBS。可從主檔選或直接輸入 | 是 |
| 規格1 | 規格前段,例:`1/4"x 6P` | 否 |
| 規格2 | 規格後段,例:`13`、`5/8"`;會與規格1合併成「規格1 × 規格2」 | 否 |
| 加工項目 | 例:車珠溝、削花溝 | 否 |
| 重量(KG) | 淨重,千分位自動加逗號 | 否 |
| 數量(pcs) | 件數,千分位自動加逗號 | 是 |
| 單位1 / 單位2 | 數量單位,可兩段組合(例 `2k+3b`) | 否 |
| 備註 | 該筆品項的備註 | 否 |

### 表單建立 — 操作步驟
1. 上方選好**廠商單位、接收單位(先選加工方式再選公司)、日期**。
2. 在「品項」區,一列填一筆:品名 → 規格1、規格2 → 加工項目 → 重量、數量、單位 → 備註。
3. 要再加一筆按「新增品項」;不要的列可刪除。最多 20 筆。
4. 右側/下方有**即時統計**(共幾筆、合計數量)。三項必填(廠商、接收、至少一筆有品名+數量)齊全才能送出。
5. 按送出 → 跳出視窗可「開啟 PDF」。

### 拖曳建單 — 操作步驟(視覺化)
畫面分三塊:**左側積木側欄**、**中間畫布**、**下方即時預覽**。

1. **拉出單位**:從左側「廠商單位 / 接收單位」把要的公司拖到畫布,它會變成一個節點;
   從該節點右側的小圓點**拉一條線連到中間的「訂單」節點**(廠商、接收各連一個就好,連新的會自動換掉舊的)。
   - 接收單位節點內是**連動下拉**:先選加工方式,右邊才跑出該方式的公司。
2. **組一排品項**:從側欄拖「品名」到畫布、連到訂單;再拖「規格1 / 規格2 / 加工 / 數量 / 單位」等欄位,
   **一個接一個用線串起來**(品名→規格1→規格2→…),這樣就組成「一排 = 一筆品項」。
   - 每個欄位節點上有「**＋**」,點它會跳出「**新增下一個欄位**」選單(只列出這排還沒有的欄位),選了會自動接上,免拉線。
   - 也可直接拖「最近使用組合」一次帶出一整排常用品項。
3. **複製整排**:右上角切到「⬚ 選取」模式框選一排(或多排),按「**複製**」會連同連線一起複製成新的一排,改數字即可(免重拉)。「✋ 移動」模式則是拖曳平移畫布。
4. **即時預覽**:畫布下方「即時預覽(會送出的內容)」會即時把畫布還原成「單頭 + 多排」,顯示共幾排、合計數量。**只有「有品名且連到訂單」的排才算數**。
5. 確認預覽正確 → 送出 → 開啟 PDF。
   - 平板沒有滑鼠拖放?可改用**點選**側欄項目(會自動放到畫布中央),再拉線連接。

### 出貨單(訂單清單)
- 用日期/關鍵字搜尋;每頁 10 筆,可翻頁。
- 每筆可:開 PDF、編輯、刪除(刪除是移到**垃圾桶**,可復原)。

### 銷貨統計
1. 選客戶(可搜尋)、帶出統一編號(可自行修改)。
2. 選日期區間 → 自動列出該客戶的明細。
3. 可調整加工單號、淨重、件數、單價;**稅率可自訂**(預設 5%),金額/稅額/總計自動算。
4. 產生 PDF(規格不換行、版面對齊統計表格式)。

### 主檔
- 分頁:廠商單位 / 接收單位 / 品名 / 加工項目 / 規格 / 套表校正。
- 可**新增、編輯(名稱/備註)、刪除**;刪除會進垃圾桶可復原。
- 接收單位有「加工方式」分類,搜尋可用名稱或縮寫。

### 垃圾桶(管理員)
- 分頁查看各類已刪資料,可**復原**或**永久刪除**(被歷史單據參照者無法永久刪除)。

### 使用紀錄(管理員)
- 條列每位使用者的登入與操作(建立/編輯/刪除、產生 PDF、使用助理…)。

### 設定(管理員)
- 帳號管理:新增使用者、停用/啟用、改角色、重設密碼。
- **聊天機器人權限**:關閉 / 僅管理員 / 所有人。

### 右下角聊天助理
- 只在**平板/電腦**顯示(手機不顯示),且需管理員開啟權限。
- 點圓圈展開對話視窗,用中文直接問。它會**記住最近幾輪對話**(預設 6 輪,超過會忘記最舊的)。
- 它**只回答**:可查詢的業務資料、網頁操作方式。
- 它**不回答**:後端技術(架構、部署、API、用什麼框架/資料庫)、資安與隱私(密碼、金鑰、權限機制、如何攻擊、其他人的資料)。
