# 資料庫結構(目前實際狀態)

> 來源:開發資料庫實際欄位(已套用全部 migration)。PostgreSQL。
> 共 8 張業務表 + `alembic_version`(migration 版本,系統用,不用管)。

## 關聯總覽

```
users ──< orders.created_by            (誰建的單)
companies ──< orders.vendor_id         (廠商單位)
companies ──< orders.receiver_id       (接收單位)
orders ──< order_items.order_id        (一張單多筆明細;刪單連動刪明細)
products ──< order_items.product_id    (來源參考,可空;品名實際存文字快照)
users ──< audit_log.user_id            (誰做的操作)

主檔(下拉/選項用):companies / products / process_items / specs
```

---

## users(使用者)
登入帳號與權限。
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| username | varchar | 登入帳號(唯一) |
| password_hash | varchar | bcrypt 雜湊(非明碼) |
| display_name | varchar | 顯示名稱 |
| role | varchar | `admin` / `operator` |
| is_active | bool | 是否啟用 |
| created_at | timestamptz | 建立時間 |

## companies(公司主檔:廠商 + 接收)
廠商單位與接收單位**完全分開**(無「兩者」),用 `role_type` 區分。
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| name | varchar | 公司名稱 |
| role_type | varchar | `vendor`(廠商) / `receiver`(接收) |
| phone | varchar | 電話 |
| fax | varchar | 傳真 |
| address | varchar | 地址 |
| note | text | 備註 |
| detail | text(JSON) | **完整原始資料**:廠商多位聯絡人陣列、統一編號(taxid);接收的加工方式等 |
| is_active | bool | |
| created_at | timestamptz | |

## products(品名主檔)
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| name | varchar | 品名 |
| default_unit | varchar | 預設單位(目前畫面未使用) |
| note | text | |
| is_active | bool | |

## process_items(加工項目主檔)
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| name | varchar | 加工項目名稱 |
| is_active | bool | |

## specs(規格主檔)
規格分「規格1 / 規格2」兩類,並用 `group_index` 記住「哪些規格1 ↔ 哪些規格2 可搭配」(建單時規格1 選了之後,規格2 只顯示同組)。
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| name | varchar | 規格值(例:`1/4"x 6P`、`13`) |
| kind | varchar | `規格1` / `規格2`(null=舊資料,兩邊可用) |
| group_index | int | 可搭配組合的分組編號 |
| is_active | bool | |

## orders(訂單:單頭)
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| order_no | varchar | 單號(唯一,YYYYMMDD-NNN) |
| vendor_id | int → companies | 廠商單位 |
| receiver_id | int → companies | 接收單位 |
| order_date | date | 日期 |
| status | varchar | `draft` / `confirmed` / `printed` / `void`(作廢) |
| is_deleted | bool | **軟刪除**:true=在垃圾桶(列表/報表預設不顯示,可復原或永久刪除) |
| total_amount | numeric | 後端重算的合計(此業務多為移轉單,金額常為 0) |
| note | text | 整張單備註 |
| created_by | int → users | 建單者 |
| created_at / updated_at | timestamptz | 建立 / 最後修改時間 |

## order_items(訂單明細:單身)
`product_name` / `spec` 是「**反正規化快照**」:建單當下寫死文字,日後改主檔不影響歷史單據。
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| order_id | int → orders | 所屬訂單(刪單連動刪) |
| sort_order | int | 行排序(支援拖曳/上下移) |
| product_name | varchar | 品名(快照) |
| product_id | int → products | 來源參考(可空) |
| spec | varchar | 規格(快照,格式「規格1 x 規格2」) |
| process_item | varchar | 加工項目 |
| net_weight_kg | numeric | 重量(KG) |
| quantity | numeric | 數量 |
| unit | varchar | 單位(格式「單位1+單位2」,例 `2k+3b`) |
| unit_price | numeric | 單價 |
| amount | numeric | 金額(後端重算 = 數量×單價) |
| remark | varchar | 品項備註 |

## audit_log(使用紀錄 / 稽核)
「誰、何時、做了什麼」——使用紀錄頁(/activity)就是讀這張。
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | int (PK) | |
| user_id | int → users | 操作者(登入當下可記) |
| action | varchar | `login` / `create_order` / `update_order` / `delete_order` / `restore_order` / `purge_order` / `generate_pdf` / `print_order` / `statement_pdf` / `create_company` / `update_company` / `create_product` / `create_process_item` / `create_spec` … |
| entity | varchar | 對象類型(order / company / sales …) |
| entity_id | int | 對象 id |
| detail | json | 額外資訊(如 order_no、customer、period) |
| created_at | timestamptz | 時間 |
